Программа для Windows, macOS и Linux, которая скачивает оригинальный IPA с подписью Apple из истории ваших покупок и устанавливает его по USB. Приложения не «протухают» через 7 дней.

Возможности программы

Без джейлбрейка

Оригинальная подпись Apple. Приложение не требует переподписи каждые 7 дней и работает как родное.

Каталог 441+ приложений

Банки (Сбер, Т-Банк, Альфа), VK, Авито, игры Supercell. Варианты одного бренда собраны в одну карточку.

Выбор версии

Если последняя версия требует новую iOS, вы можете выбрать и установить более старую, совместимую версию.

Очередь установок

Нажмите «Установить» у нескольких приложений сразу. Они поставятся по очереди с отображением прогресса.

Безопасность

Пароль передаётся только на серверы Apple. Сессия хранится локально в зашифрованном виде. Открытый исходный код.

Кроссплатформенность

Работает на Windows 10/11, macOS 12+ (Intel и Apple Silicon) и Linux (Ubuntu 22.04+). Python ставить не нужно.

Как это устроено

1

Вход в Apple ID

Программа запрашивает историю ваших покупок напрямую у серверов Apple (с поддержкой 2FA).

2

Скачивание IPA

Утилита ipatool скачивает оригинальный файл приложения с вашей подписью из истории покупок.

3

Установка по USB

pymobiledevice3 передаёт и устанавливает приложение на разблокированный iPhone по кабелю.

Частые вопросы

Появится ли надпись «Недоверенный разработчик»?

Нет. Приложение скачивается с оригинальной подписью Apple из вашей истории покупок, поэтому система воспринимает его как легитимно установленное из App Store.

Пишет «Этого приложения нет в истории покупок»

Это означает, что вы никогда не скачивали это приложение с данного Apple ID. Попробуйте другой вариант названия в разделе «Все варианты…» или войдите в аккаунт, с которого приложение скачивалось ранее.

Программа не видит iPhone

Windows: Установите приложение «Устройства Apple» (Apple Devices) из Microsoft Store или iTunes.
Linux: Установите и запустите службу usbmuxd.
Убедитесь, что телефон разблокирован и вы нажали «Доверять этому компьютеру» на экране iPhone.

Безопасно ли вводить пароль Apple ID?

Да. Программа имеет открытый исходный код. Пароль передаётся напрямую на серверы Apple. Сессия хранится локально в зашифрованном виде и не отправляется разработчику.

Возврат (Back to iPhone)

Проект с открытым исходным кодом для личного использования. Мы не связаны с Apple Inc. и не распространяем чужие приложения: всё скачивается с серверов Apple под вашим Apple ID.
