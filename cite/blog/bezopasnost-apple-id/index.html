Безопасно ли вводить пароль Apple ID в «Возврате»

Куда уходит пароль, как защищён локальный сервер и что делать, если вы пользовались другими ipatool-программами.

Куда уходит пароль

Только на серверы Apple. Программа работает на вашем компьютере (127.0.0.1), а вход выполняет ipatool. Двухфакторная аутентификация поддерживается: код вводится в самой программе.

Как защищён локальный сервер

Локальный HTTP-сервер программы защищён случайным токеном и проверкой заголовка Host, поэтому посторонние страницы в браузере не смогут им воспользоваться.

Где хранится сессия

На Windows и Linux — в зашифрованном ipatool-home внутри папки программы, на macOS — в связке ключей.

Если вы пользовались IPA_Downloader и подобными

«Возврат» хранит сессию отдельно от других программ на ipatool: на macOS и Linux — начиная с версии 1.1.0, на Windows — с версии 1.4.1 (до неё на Windows сессия лежала в общей папке .ipatool, и 1.4.1 при первом запуске переносит её к себе). Если вход не работает после других программ на ipatool, просто войдите в «Возврат» ещё раз.

Проверяйте самиИсходный код открыт. Если вы не готовы доверять сборке, соберите программу из исходников: инструкция есть в README репозитория.
