Возврат

Доступна новая версия . Обновление займёт около минуты.

Возвращает на iPhone приложения, удалённые из App Store: скачивает оригинальный IPA из истории покупок вашего Apple ID и ставит его по USB.

1Apple ID

Нужен тот Apple ID, с которого приложение когда-то скачивалось. Пароль уходит только на серверы Apple; для автоматического перелогина он хранится в зашифрованном виде на этом компьютере (ipatool). Первый вход может занять 1–3 минуты.

2iPhone

Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».

↻Обновления приложений

Удалённые из App Store приложения не обновляются сами. «Возврат» сравнит версии на iPhone с последними версиями в истории покупок вашего Apple ID.

⇊Вернуть всё сразу

«Возврат» найдёт приложения каталога, которые есть в истории покупок вашего Apple ID, но ещё не стоят на iPhone, и поставит их одной кнопкой. Проверка идёт без скачивания — по запросу к App Store на каждое приложение, поэтому для всего каталога займёт несколько минут.

Вопросы

Приложение не найдено в истории покупок. Его нужно было хоть раз скачать с этого Apple ID до удаления из App Store. Попробуйте другой Apple ID.

Не приходят push-уведомления. Для некоторых удалённых приложений Apple отключила пуши — это ограничение Apple.

Компьютер не видит iPhone. Переподключите кабель, разблокируйте iPhone и нажмите «Доверять».

Обновления. Удалённые приложения не обновляются через App Store. Чтобы получить свежую версию (если разработчик её выпустил), установите приложение снова.
